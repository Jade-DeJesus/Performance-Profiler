Dataset Instructions

This system evaluates the performance of search algorithms using an e-commerce dataset.

You can either:

  • Upload your own dataset (CSV or JSON)
  • Generate a sample dataset automatically

Each dataset record should contain the following fields: SKU, Name, Category, Price, Stock

Recommended dataset sizes:

  • 10,000 records (Small Baseline)
  • 50,000 records (Medium Testbed)
  • 100,000 records (Large Baseline)
  • 500,000 records (Very Large Testbed)
  • 1,000,000 records (Massive / Stress-Test Scale)

Benchmark Information

  • Search Test: Performs random SKU lookups to measure search performance across in-memory collections
  • Distribution Effects: Uniform datasets allow interpolation to converge in ≈ O(log log N) steps, while Non-Uniform (skewed/clustered) datasets stress interpolation accuracy and highlight differences between Binary, Fibonacci, and Exponential hybrid fallbacks.
  • Algorithms Benchmarked: Automatically runs all three Interpolation variants (Binary, Fibonacci, Exponential).
